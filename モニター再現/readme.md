# AviUtl2 携帯ゲーム機モニター再現スクリプトセット

携帯ゲーム機（Game & Watch、ゲームボーイ、ゲームボーイカラー、ゲームボーイアドバンス、ニンテンドーDS、ニンテンドー3DS）の液晶を再現するAviUtl2スクリプト群です。


---

## 一覧

すべてのエフェクトは **「画面効果\モニター再現」** メニュー内に追加されます。

| ファイル名 | 登録エフェクト名 | 種別 |
| :--- | :--- | :--- |
| `解像度変更.anm2` | 解像度変更 | 画面効果 |
| `@GB風.anm2` | GBモニター再現<br>GB電源OFF | 画面効果 |
| `@GBC風.anm2` | GBCモニター再現<br>GBC電源OFF | 画面効果|
| `GBA風.anm2` | GBAモニター再現 | 画面効果 |
| `NDS風.anm2` | NDSモニター再現 | 画面効果 |
| `3DS風.anm2` | 3DSモニター再現 | 画面効果 |
| `Game&Watch風.anm2` | Game&Watch風 | 画面効果 |

## 各スクリプトの機能とパラメータ解説

### 1. 解像度変更 (`解像度変更.anm2`)
指定したゲーム機の実機アスペクト比に基づき、仮想スクリーン領域を生成してリサイズ・配置します。後続のモニター再現スクリプトの前処理として使用できます。

* **機種解像度**: ハードの基本解像度（GB/GBC: 160×144、GBA: 240×160、NDS: 256×192、3DS上: 400×240、3DS下: 320×240、カスタム）を選択します。
* **画面倍率**: 仮想スクリーンの表示スケール倍率を設定します。
* **リサイズ方式**: 元映像の収め方（クリッピング / 内接 / 外接 / 比率無視）を選択します。
* **中心X / 中心Y**: クリッピング時の中心位置をオフセットします。
* **カスタム幅 / カスタム高さ**: 機種解像度で「カスタム」を選択した際のピクセル数を指定します。
* **ドット補間(ニアレスト)**: ニアレストネイバー補間により、ドット絵の輪郭をぼかさずにスナップします。

---

### 2. 初代ゲームボーイ (`@GB風.anm2`)

#### GBモニター再現
DMG-01（初代ゲームボーイ）のSTNモノクロ液晶を再現します。

* **実機解像度に合わせる**: 有効化すると、縦144ドットを基準にアスペクト比を維持した正方形ドットへ自動スナップします。
* **ドットサイズ**: 「実機解像度に合わせる」が無効の際、任意のドットサイズを指定します。
* **グリッド濃度**: ピクセル間のブラックマトリクス（網目）の濃さを設定します。
* **影の距離 / 影の角度**: 液晶素子から背面反射板へ落ちる影の距離と方向を指定します。
* **縦クロストーク**: パッシブマトリクス駆動特有の、同一列の点灯素子集中に伴う縦方向の薄い寄生影の強さを設定します。
* **パレット**: 実機風（緑 / グレー）、または3DSバーチャルコンソール風（緑 / グレー）の4階調配色を選択します。

#### GB電源OFF
STN液晶の通電遮断アニメーション（電圧降下によるコントラスト低下 → パネル色同化 → 最終放電発光）を実行します。

* **進行度**: アニメーションの進行状況（0.0〜100.0%）を指定します。
* **パレット**: モニター再現と合わせたカラーパレットを選択します。

---

### 3. ゲームボーイカラー (`@GBC風.anm2`)

#### GBCモニター再現
CGB-001（ゲームボーイカラー）の反射型カラーTFT液晶を再現します。

* **実機解像度に合わせる**: 有効化すると、縦144ドット基準の正方形ドットへ自動スナップします。
* **ドットサイズ**: ドットの大きさを任意指定します（実機解像度OFF時のみ表示）。
* **環境光(明るさ)**: 外光反射の強度を調整します。
* **色補正強度**: 実機分光特性に基づいた3×3混色マトリクスの適用度合を調整します（100%で実機のくすんだパステル調、0%で原色の鮮やかさを維持）。
* **グリッド濃度 / 影の距離 / 影の角度**: 格子の濃さおよび反射板への影を調整します。
* **サブピクセル表示**: RGBストライプ状のサブピクセル分離を描画します。
* **15bitカラー化**: 15-bit RGB（32,768色）に色数を量子化します。

#### GBC電源OFF
カラー液晶の通電遮断アニメーション（彩度低下 → パネル色への溶け込み → 残像消失）を実行します。

* **進行度**: アニメーションの進行状況（0.0〜100.0%）を指定します。

---

### 4. ゲームボーイアドバンス (`GBA風.anm2`)
GBAシリーズの光学特性（反射型・フロントライト・バックライト）を再現します。

* **モデル**: 
  * `初代GBA(反射型)`: 光源なし、暗めのパネル色、過彩度補正ガンマ展開。
  * `GBA SP(フロントライト)`: 前面導光板による白浮き・光反射。
  * `GBA SP(バックライト)`: 高コントラスト・透過発光。
* **実機解像度に合わせる**: 有効化すると、縦160ドット基準の正方形ドットへ自動スナップします。
* **ドットサイズ**: ドットの大きさを任意指定します（実機解像度OFF時のみ表示）。
* **明度補正**: パネル全体の明るさを底上げし、視認性を向上させます。
* **色補正強度**: GBA専用のガンマ減衰および混色マトリクス強度を調整します。
* **グリッド濃度**: ピクセル間の配線（ブラックマトリクス）の濃さを調整します。
* **サブピクセルとノッチ**: RGBサブピクセルおよびTFTトランジスタの薄膜影（ノッチ）を描画します。
* **BGRサブピクセル配列**: 有効化すると、バックライトモデル等に見られる逆順（BGR）のサブピクセル配列へ切り替えます。
* **15bitカラー化**: 15-bit RGB（32,768色）に色数を量子化します。

---

### 5. ニンテンドーDS (`NDS風.anm2`)
DSシリーズのデュアルスクリーン液晶特性を再現します。

* **モデル**: 
  * `初代DS (NTR)`: 低コントラスト、標準的な格子幅。
  * `DS Lite (USG)`: 高輝度・ニュートラル、極細格子。
  * `DSi LL (UTL)`: 広色域IPS、ピクセルピッチ拡大による強調格子。
* **画面**: `上画面` または `下画面(タッチ)` を選択します。下画面選択時は抵抗膜タッチパネル（ITOフィルム）による光量減衰・黄ばみ・表面乱反射ノイズが付加されます。
* **実機解像度に合わせる**: 有効化すると、縦192ドット基準の正方形ドットへ自動スナップします。
* **ドットサイズ**: ドットの大きさを任意指定します（実機解像度OFF時のみ表示）。
* **明るさ**: 画面全体の輝度を調整します。
* **ピクセル隙間濃度**: ピクセル間の網目の濃さを設定します。
* **サブピクセル表示**: RGB縦ストライプ状のサブピクセル分離を描画します。

---

### 6. ニンテンドー3DS (`3DS風.anm2`)
3DSシリーズの液晶特性および視差バリア方式の裸眼3D構造を再現します。

* **モデル**: 
  * `3DS TN液晶(標準)`: 標準的な発色、下画面選択時は自動でTN特性を適用。
  * `3DS IPS液晶(当り)`: 高コントラスト・鮮やかな発色。
  * `2DS(スリット無)`: 視差バリア層を持たないクリアな単一パネル特性。
* **画面**: `上画面(3D)`（400×240相当）または `下画面(タッチ)`（320×240相当）を選択します。
* **実機解像度に合わせる**: 有効化すると、選択した画面に応じた縦240ドット基準の正方形ドットへ自動スナップします。
* **ドットサイズ**: ドットの大きさを任意指定します（実機解像度OFF時のみ表示）。
* **明るさ**: 画面全体の輝度を調整します。
* **サブピクセル強度**: RGBストライプの分離度を調整します（過剰なカラーモアレを防ぐ場合は数値を下げてください）。
* **3Dバリア濃度**: 裸眼3D用の視差バリア（縦スリット遮光線）の濃さを設定します（上画面かつ3DSモデル時のみ有効）。
* **視差アングル(3Dシフト)**: 視点移動に伴うバリアスリットの横シフト量を調整します。

---

### 7. Game & Watch (`Game&Watch風.anm2`)
印刷背景カードの上にセグメント型STN液晶が浮遊する構造を再現します。

* **低解像度化**: 映像を粗いブロック状にダウンサンプリングしてからセグメント化します。
* **解像度分割数**: 低解像度化ON時の縦方向のサンプリング分割数を設定します。
* **2値化しきい値**: 入力映像をセグメントON/OFFに振り分ける輝度しきい値を設定します。
* **影の距離**: 前面ガラスの厚みによって反射板へ落ちる影の距離を設定します。
* **非通電残光(ゴースト)**: 通電していない（OFF状態の）セグメントがうっすらと見える偏光残光影の濃さを設定します。
* **背景(反射板)**: 背景カード（反射板）の色を指定します。
* **液晶(セグメント)**: 点灯する液晶セグメントの色を指定します。
