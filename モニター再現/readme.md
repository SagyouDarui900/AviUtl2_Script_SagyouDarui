# AviUtl 2 携帯ゲーム機モニター再現スクリプト

Game & Watch、ゲームボーイ、ゲームボーイカラー、ゲームボーイアドバンス、ニンテンドーDS、ニンテンドー3DSの画面をイメージした、AviUtl 2用の画面効果スクリプト集です。

実機の液晶パネル、反射、サブピクセル、ブラックマトリクス、視差バリアなどを参考にした近似表現です。実機の個体差や撮影環境まで含めた完全な再現ではありません。

## 対応スクリプト

| ファイル | エフェクト | 主な用途 |
|---|---|---|
| `解像度変更.anm2` | 解像度変更 | 実機解像度を基準にしたリサイズ |
| `@GB風.anm2` | GBモニター再現 / GB電源OFF | 初代ゲームボーイ風の表示 |
| `@GBC風.anm2` | GBCモニター再現 / GBC電源OFF | ゲームボーイカラー風の表示 |
| `GBA風.anm2` | GBAモニター再現 | ゲームボーイアドバンス風の表示 |
| `NDS風.anm2` | NDSモニター再現 | ニンテンドーDS風の表示 |
| `3DS風.anm2` | 3DSモニター再現 | ニンテンドー3DS風の表示 |
| `Game&Watch風.anm2` | Game&Watch風 | セグメント液晶風の表示 |

インストール後は、画面効果の `モニター再現` メニューから使用します。AviUtl 2のScriptフォルダ、またはその1階層下のフォルダにスクリプトを配置してください。

## 推奨ワークフロー

1. 必要に応じて `解像度変更` を適用する。
2. 入力映像の収め方、画面倍率、補間方法を設定する。
3. 対応するモニター再現エフェクトを適用する。
4. 実機解像度に合わせる場合は、各エフェクトの `実機解像度に合わせる` を有効にする。

`解像度変更` は必須ではありません。モニター再現エフェクト単体でも使用できます。

## 実機解像度モード

`実機解像度に合わせる` を有効にすると、入力素材の縦横比から分割数を推定するのではなく、対象機種の実機解像度をそのまま使用します。

| 対象 | 解像度 |
|---|---:|
| GB / GBC | 160×144 |
| GBA | 240×160 |
| NDS | 256×192 |
| 3DS 上画面 | 400×240 |
| 3DS 下画面 | 320×240 |

このモードでは、素材の解像度やアスペクト比が実機と異なっていても、シェーダー内部のピクセル分割数は固定されます。表示範囲や素材の収め方は、必要に応じて `解像度変更` のリサイズ方式で調整してください。

実機解像度モードを無効にした場合は、`ドットサイズ` とオブジェクトサイズから分割数を計算します。細かい表示やオリジナルの画面比率を優先したい場合に使用してください。

## 解像度変更

### 解像度

対象機種に合わせて、次の仮想画面サイズを選択できます。

- GB / GBC: 160×144
- GBA: 240×160
- NDS: 256×192
- 3DS 上画面: 400×240
- 3DS 下画面: 320×240
- カスタム

### リサイズ方式

- `クリッピング(中央切抜)`: 中央を基準に入力映像を切り抜く
- `内接(レターボックス)`: 全体が収まるように縮小し、余白を透明にする
- `外接(クロップ)`: 画面全体を埋め、はみ出した部分を切り抜く
- `比率無視`: 入力映像を指定領域へそのまま伸縮する

`中心X` と `中心Y` は、クリッピング時の切り抜き位置を調整します。`ドット補間(ニアレスト)` は、ピクセルアートの拡大・縮小時に補間によるぼやけを抑えます。

## GB風

### GBモニター再現

初代ゲームボーイ（DMG）の反射型STNモノクロ液晶をイメージした表示です。

- `実機解像度に合わせる`: 160×144へ固定
- `ドットサイズ`: 実機解像度モードを無効にした場合の分割サイズ
- `グリッド濃度`: ピクセル間のブラックマトリクスの濃さ
- `影の距離`: 液晶素子の影の距離
- `影の角度`: 液晶素子の影の方向。初期値は45度
- `縦クロストーク`: パッシブマトリクス由来の縦方向の寄生影
- `パレット`: GB風または3DSバーチャルコンソール風の緑・グレー配色

### GB電源OFF

GB風のパレットを使用した電源OFFアニメーションです。`進行度` を0〜100%で指定します。モニター再現とは別の画面効果として使用できます。

## GBC風

ゲームボーイカラー（CGB）の反射型カラー液晶をイメージした表示です。

- `実機解像度に合わせる`: 160×144へ固定
- `ドットサイズ`: 実機解像度モードを無効にした場合の分割サイズ
- `環境光(明るさ)`: 外光・反射型液晶の明るさ
- `色補正強度`: 色のくすみや液晶特性の補正量
- `グリッド濃度`: ピクセル間の網目の濃さ
- `影の距離` / `影の角度`: 液晶素子の影の位置
- `サブピクセル表示`: RGBストライプの表示
- `15bitカラー化`: RGB各5bit相当への量子化

`GBC電源OFF` は、GBC風の色を基準にした通電遮断アニメーションです。`進行度` を0〜100%で指定します。

## GBA風

ゲームボーイアドバンス各モデルの画面特性を近似します。

- `初代GBA(反射型)`: 光源のない暗めの反射型表示
- `GBA SP(フロントライト)`: 前面ライトによる白浮きや反射
- `GBA SP(バックライト)`: 明るくコントラストの高い表示

共通パラメータ:

- `実機解像度に合わせる`: 240×160へ固定
- `ドットサイズ`: 実機解像度モードを無効にした場合の分割サイズ
- `明度補正`: 画面全体の明るさ
- `色補正強度`: GBA向けの色・ガンマ補正量
- `グリッド濃度`: ピクセル間の配線・マトリクス表現
- `サブピクセルとノッチ`: サブピクセルと薄膜トランジスタの影
- `BGRサブピクセル配列`: サブピクセル順をBGRに変更
- `15bitカラー化`: RGB各5bit相当への量子化

## NDS風

ニンテンドーDSのデュアルスクリーン液晶をイメージした表示です。1回の適用で上画面または下画面のどちらかを再現します。

- `モデル`: 初代DS、DS Lite、DSi LL
- `画面`: 上画面または下画面（タッチ）
- `実機解像度に合わせる`: 256×192へ固定
- `ドットサイズ`: 実機解像度モードを無効にした場合の分割サイズ
- `明るさ`: 画面全体の輝度
- `ピクセル隙間濃度`: ブラックマトリクスの濃さ
- `サブピクセル表示`: RGBストライプの表示

下画面を選択すると、抵抗膜タッチパネルをイメージした光量低下、色かぶり、表面ノイズが追加されます。

## 3DS風

ニンテンドー3DSの上画面・下画面と、上画面の裸眼3D表示をイメージした表示です。

- `モデル`: 3DS TN液晶、3DS IPS液晶、2DS
- `画面`: 上画面（3D）または下画面（タッチ）
- `実機解像度に合わせる`: 上画面は400×240、下画面は320×240へ固定
- `ドットサイズ`: 実機解像度モードを無効にした場合の分割サイズ
- `明るさ`: 画面全体の輝度
- `サブピクセル強度`: RGBストライプの強さ
- `3Dバリア濃度`: 上画面の視差バリアの濃さ
- `視差アングル(3Dシフト)`: 視差バリアの横方向の位相

`3Dバリア濃度` と `視差アングル(3Dシフト)` は、3DSモデルの上画面でのみ有効です。下画面と2DSモデルでは視差バリアを適用しません。

## Game & Watch風

セグメント型STN液晶と反射板をイメージした表示です。Game & Watchは機種ごとにセグメント配置や画面サイズが異なるため、特定タイトルの完全再現ではなく、汎用的なセグメント液晶表現として使用してください。

- `低解像度化`: 入力映像をブロック状にサンプリング
- `解像度分割数`: 低解像度化時の縦方向の分割数
- `2値化しきい値`: セグメントの点灯判定
- `影の距離`: 液晶素子から反射板へ落ちる影
- `非通電残光(ゴースト)`: OFFセグメントの残像・漏れ表示
- `背景(反射板)`: 背景カードや反射板の色
- `液晶(セグメント)`: 点灯セグメントの色

`低解像度化` を無効にすると、入力映像の座標を直接使用します。解像度分割数はその場合は使用されません。

## 透明部分と描画について

各エフェクトは、入力オブジェクトのアルファ値を基準に描画します。透明部分を含む素材では、透明部分を保ったままモニター表現を適用できます。

## 注意事項

- 本スクリプトは実機の光学・電気特性を参考にした近似表現です。
- 液晶の色、明るさ、反射、視野角、サブピクセル構造は機種・個体・撮影条件によって異なります。
- 3DSの裸眼3Dは、実際の左右画像や視聴者の視点まで再現するものではなく、画面上の視差バリア表現です。
- Game & Watchのセグメント配置はタイトルごとに異なります。
- 使用によって生じた損害や不具合について、作者は責任を負いません。
