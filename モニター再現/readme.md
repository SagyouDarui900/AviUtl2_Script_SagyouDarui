# AviUtl 2 携帯ゲーム機モニター再現スクリプト

Game & Watch、ゲームボーイ、ゲームボーイカラー、ゲームボーイアドバンス、ニンテンドーDS、ニンテンドー3DSの画面表示をイメージした、AviUtl 2 用の画面効果（`.anm2`）スクリプト集です。

HLSL ピクセルシェーダーによる GPU 処理を採用しており、実機の液晶パネル特性・外光反射・サブピクセル配列・ブラックマトリクス・視差バリアなどを参考にした近似表現をリアルタイムに適用できます。

> **Note**  
> 本スクリプトは実機の光学・電気特性を参考にした近似表現です。実機の個体差、経年変化、撮影環境まで含めた完全な再現ではありません。

## 導入方法

1. すべての `.anm2` ファイルをダウンロードします。
2. AviUtl 2 の `Script` フォルダ（例: `C:\ProgramData\aviutl2\Script\`）、またはその 1 階層下のサブフォルダにファイルを配置します。
3. AviUtl 2 を起動（または再読み込み）すると、フィルタ効果の **`画面効果` > `モニター再現`** カテゴリから各エフェクトを選択できます。

## 基本的な使い方

### パターン A：モニター再現エフェクト単体で使う（手軽な方法）

動画や画像オブジェクトに直接 `GBモニター再現` や `GBA風` などを適用します。  
既定では **`実機解像度に合わせる`** と **`ドット比率を正方形に保つ`** が両方有効になっているため、16:9 などの一般的な動画素材にそのまま適用しても、ドットが縦横に引き伸ばされることなく正方形のグリッドで描画されます。

### パターン B：`解像度変更` と組み合わせて実機比率で使う

1920×1080 などの映像から実機のアスペクト比で画面を切り出したい場合は、`解像度変更` を先に適用します。

1. オブジェクトに **`解像度変更`** を適用し、対象機種と `画面倍率`、`リサイズ方式` を設定します。
2. その下（後段）に、対応するモニター再現エフェクトを適用します。

#### `解像度変更` と併用する際の注意点

1920×1080 などの大きいオブジェクトに `解像度変更` を適用すると、キャンバス中央に仮想画面が描画されますが、オブジェクト自体の外枠サイズ（`obj.w × obj.h`）は元のまま維持されます。  
この状態で後段エフェクトの `実機解像度に合わせる` を有効にすると、透明余白を含むオブジェクト全体に対して分割数が割り当てられるため、仮想画面のドットとグリッドがずれます。

ドットを 1 対 1 でぴったり合わせる場合は、次のどちらかの方法をとってください。

- **方法 1（推奨）**: 後段のモニター再現エフェクトで **`実機解像度に合わせる` をオフ** にし、**`ドットサイズ`** を `解像度変更` の **`画面倍率`** と同じ数値に設定する。
- **方法 2**: フレームバッファやオブジェクトサイズ自体をあらかじめ「実機解像度 × 整数倍（例: 1600×960）」に揃えたうえで、`実機解像度に合わせる` をオンにする。

## パラメータ詳細

### 解像度変更（`解像度変更.anm2`）

| パラメータ | 初期値 | 説明 |
|---|---|---|
| `機種解像度` | `GB/GBC (160x144)` | `GB/GBC (160x144)`、`GBA (240x160)`、`NDS (256x192)`、`3DS上 (400x240)`、`3DS下 (320x240)`、`カスタム` から選択します。 |
| `画面倍率` | `4.0` | 選択した基準解像度に対する表示倍率です（例: 160×144 で倍率 4.0 の場合、640×576 で描画）。 |
| `リサイズ方式` | `クリッピング(中央切抜)` | 仮想画面への収め方を選択します。<br>・`クリッピング(中央切抜)`: 中央を基準に入力を切り抜きます。<br>・`内接(レターボックス)`: 全体が収まるよう縮小し、余白を透明にします。<br>・`外接(クロップ)`: 画面全体を埋め、はみ出した部分を切り抜きます。<br>・`比率無視`: 縦横比を維持せず指定領域へ伸縮します。 |
| `中心位置` (`中心X` / `中心Y`) | `0` / `0` | `クリッピング` および `外接` 選択時の切り抜き基準位置（px）を調整します。 |
| `カスタム解像度` (`カスタム幅` / `カスタム高さ`) | `160` / `144` | `機種解像度` で `カスタム` を選択した際の基準解像度を指定します。 |
| `ドット補間(ニアレスト)` | `OFF` | ON にするとニアレストネイバー補間でドットの輪郭をくっきり保ちます。OFF 時は縮小率に応じたエリア平均補間を行い、モアレを抑えます。 |

### GB風（`@GB風.anm2`）

#### `GBモニター再現`

初代ゲームボーイ（DMG）の反射型 STN モノクロ液晶をイメージしたエフェクトです。

| パラメータ | 初期値 | 説明 |
|---|---|---|
| `実機解像度に合わせる` | `ON` | 縦 144 ドット（横 160 ドット）を基準にグリッド分割します。 |
| `ドット比率を正方形に保つ` | `ON` | `実機解像度に合わせる` が ON のとき、オブジェクトの縦横比に合わせて横または縦の分割数を自動調整し、ドットを正方形に保ちます。OFF にすると 160×144 に固定します。 |
| `ドットサイズ` | `4.0` | `実機解像度に合わせる` が OFF のときの 1 ドットあたりのピクセルサイズです。 |
| `グリッド濃度` | `60` | ドット間のブラックマトリクス（隙間）の濃さです。 |
| `影の距離` | `1.5` | 液晶素子から背面反射板へ落ちる影の距離です。 |
| `影の角度` | `45.0` | 影が落ちる方向（度）です。 |
| `縦クロストーク` | `25` | パッシブマトリクス液晶特有の、縦方向の濃淡に応じた寄生影（スミア）の強さです。 |
| `パレット` | `GB風(緑)` | `GB風(緑)`、`GB風(グレー)`、`3DSVC風(緑)`、`3DSVC風(グレー)` の 4 階調パレットから選択します。 |

#### `GB電源OFF`

GB パレットをベースにした電源遮断時のコントラスト変化・フェード演出です。

| パラメータ | 初期値 | 説明 |
|---|---|---|
| `進行度` | `0.0` | `0`（通常表示）〜 `100`（完全消灯）の間でアニメーション進行度を指定します。 |
| `パレット` | `GB風(緑)` | 消灯先のパネル背景色を 4 種類のパレットから選択します。 |

> 3DS モデル（TN / IPS）の `上画面(3D)` では、物理 800×240 パネルを左右の目に割り振る半幅画素構造を模した中央縦スリットが自動的に再現されます。

### Game&Watch風（`Game&Watch風.anm2`）

モノクロのセグメント型 STN 液晶と反射板をイメージしたエフェクトです。  
実機の Game & Watch はタイトルごとに専用の固定セグメント電極を持つ構造のため、本エフェクトは入力映像の明暗を 2 値化してセグメント液晶の質感を与える汎用表現となっています。

| パラメータ | 初期値 | 説明 |
|---|---|---|
| `低解像度化` | `OFF` | ON にすると入力映像を指定の分割数でブロックサンプリングします。 |
| `解像度分割数` | `80` | `低解像度化` が ON のときの縦方向の分割数です。 |
| `2値化しきい値` | `50` | 入力輝度に対してセグメントを点灯（黒化）させるしきい値です。 |
| `影の距離` | `5.0` | 点灯セグメントから背面反射板へ落ちるドロップシャドウの距離です。 |
| `非通電残光(ゴースト)` | `8` | 消灯状態のセグメントが背景上にうっすら浮かび上がる表現の強さです。 |
| `背景(反射板)` | `0x9dae9c` | 反射板（背景）の色を指定します。 |
| `液晶(セグメント)` | `0x111111` | 点灯した液晶セグメントの色を指定します。 |

## 仕様・注意事項

- **透明部分の保持**: すべてのエフェクトはプリマルチプライドアルファに対応しており、透過 PNG やテロップなどの透明部分を維持したまま液晶効果を適用できます。
- **時間軸の残像について**: 初代ゲームボーイ（STN 液晶）などのフレームをまたぐ時間軸残像は、単一フレームのピクセルシェーダー構造上含まれていません。必要に応じて AviUtl 2 標準の残像・ブラー系エフェクトと併用してください。
